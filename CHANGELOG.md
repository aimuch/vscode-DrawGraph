# Changelog

## 0.5.0

- **Multi-Provider AI Engine & OS Keychain SecretStorage (`src/ai/aiProviders.ts`)**: Added first-class support for **VS Code Built-in LM (`vscode.lm`)**, **DeepSeek**, **Kimi (Moonshot)**, **Doubao (Volcengine Ark)**, **Qwen (DashScope)**, **OpenAI**, **Ollama**, **Magpie Gateway** (auto-discovering `~/.config/magpie/gateway.json`), **CC Switch Gateway**, and **OpenAI Compatible** endpoints, with `GET /models` auto-discovery (`DrawGraph: Discover Available AI Models…`), SSE streaming + `<think>` reasoning-tag filtering, per-host privacy consent, `machine`-scoped configuration hardening, and API keys stored exclusively in `vscode.SecretStorage`.
- **Interactive AI Diagram Studio (`DrawGraph: Open AI Diagram Studio`)**: Side-by-side conversational diagramming workbench across all 5 formats (**Mermaid**, **Draw.io**, **PlantUML**, **Graphviz DOT**, **WaveDrom**) with 5 specialized modes (**Generate**, **Modify**, **Optimize** with 5 presets `layout`/`style`/`simplify`/`resilience`/`translate`, **Fix Syntax**, and **Explain & Architecture Review** with `[HIGH]`/`[MEDIUM]`/`[LOW]`/`[INFO]` findings cards), optional active-editor/selection code context, live rendered SVG preview, and one-click **Apply to Active Diagram** (preserving native Undo on text diagrams and live-updating open `.drawio`/`.drawio.svg`/`.drawio.png` editors).
- **In-Memory Before ↔ After Visual Diff Preview for AI Edits**: Preview AI-proposed diagram modifications in Side-by-Side, Swipe, or Onion/Pixel Diff mode (`VisualDiffManager.openInMemoryComparison`) before applying them to your file.
- **One-Click AI Syntax Auto-Repair & Editor Integrations**: Wired `DrawGraph: Fix Diagram Syntax with AI` into VS Code's lightbulb **Quick Fix (`CodeActionProvider`)** on diagram diagnostics AND an inline **`✨ Fix with AI`** button inside the Diagram Preview error banner, plus editor selection context menu (`Generate Diagram from Selection with AI…`), CodeLens (`$(sparkle) AI Studio`), Quick Menu, and full Settings Drawer AI configuration (`中 / EN`).

## 0.4.0

- **Broken Code-Link Diagnostics & Refactor-Aware Path Sync (`DrawGraph: Audit Broken Diagram Code Links`)**: Automatically flags missing local file references inside diagrams in the VS Code **Problems** panel with one-click Quick Fixes to relocated files, and listens to `workspace.onDidRenameFiles` (`drawGraph.codeLinks.syncOnFileRename`) to rewrite relative file paths across `.drawio`, `.drawio.svg`, `.mmd`, `.puml`, and `.md` diagrams when source files move.
- **Live Editor Cursor & Debugger Stack Sync (`drawGraph.preview.syncWithCodeCursor`)**: Moving the cursor through source classes/functions or pausing on a stack frame in the VS Code debugger automatically highlights and centers matching architecture nodes in open Diagram Previews and updates the Draw.io Code-Link status indicator.
- **WaveDrom (`.wavedrom`, `.wave.json`) & Graphviz DOT (`.dot`, `.gv`) Native Offline Support**: Zero-dependency TypeScript engines for WaveDrom digital timing waveforms (`signal`), BitField hardware register tables (`reg`), and Graphviz DOT clustered DAGs (with optional local `dot -Tsvg` CLI acceleration), integrated across live preview, Markdown ```` ```wavedrom ```` / ```` ```dot ```` fences, Document Outline, static diagnostics, Visual Diff, and SVG/PNG/PDF/HTML export.
- **OpenAPI / Protobuf / Prisma Schema Generators (`DrawGraph: Generate Diagram from OpenAPI / Proto / Prisma…`)**: Convert OpenAPI 3.x / Swagger 2.0 (`YAML` or `JSON`), Protocol Buffers (`.proto` services & messages), and Prisma (`schema.prisma` models & `@relation` foreign keys) into **Mermaid**, **PlantUML**, or editable **Draw.io** diagrams.
- **Docker Compose & GitHub Actions Topology Generators (`DrawGraph: Generate Topology from Docker Compose / GitHub Actions…`)**: Visualize `docker-compose.yml` services, ports, networks, volumes, and `depends_on` edges, or `.github/workflows/*.yml` trigger-to-job `needs` DAG pipelines.
- **Draw.io → Mermaid / PlantUML Reverse Conversion (`Convert Draw.io Diagram to Mermaid` / `PlantUML`)**: Completes full bidirectional format conversion by extracting `<mxfile>` vertices, swimlane/group containers, shape semantics (`rhombus`, `cylinder3`, `ellipse`, `umlActor`), and labeled/dashed edges back into structured Mermaid or PlantUML text.
- **Standalone Interactive HTML Presentation Export (`DrawGraph: Export Diagram as Interactive HTML…`)**: Package single or multi-page diagrams into a self-contained, zero-network `.html` file with multi-page tabs, cursor-anchored wheel zoom, drag pan, minimap, live node search, Light/Dark/Grid themes, and Spotlight + Laser Pointer presentation mode.
- **Code Comment & Markdown Hover Thumbnails + Explorer Drag-and-Drop**: Hovering over diagram paths in source code comments (`@see docs/arch.drawio`) or Markdown displays rendered inline SVG/PNG thumbnails with one-click `Open Diagram` and `Visual Diff` actions; dragging diagrams from the **Diagrams** Explorer tree into `.md` inserts clean relative Markdown image/file references.
- **Branch-Level Batch Visual Diagram Review & Workspace Library Auto-Mount**: Compare all modified diagrams against any Git branch or commit (`DrawGraph: Review All Modified Diagrams vs Branch…`) with an in-toolbar `◀ 1/N ▶` file switcher, and automatically mount `.vscode/drawgraph-library.xml` into Draw.io (`DrawGraph: Create Workspace Shape Library`).

## 0.3.0

- **Git Visual Diagram Diff (`DrawGraph: Visual Diagram Diff vs Git HEAD` & `Compare Two Diagram Files Visually…`)**: Interactive visual diff viewer for `.drawio`, `.drawio.svg`, `.drawio.png`, `.mmd`, and `.puml` files from the Source Control (SCM) context menu or editor toolbar, featuring baseline Git commit/ref switching (`HEAD`, `HEAD~1`, history log), multi-page Draw.io selector with unified coordinate bounding-box alignment, cursor-anchored **Side-by-Side** pan/zoom, keyboard-accessible **Swipe** curtain, and **Onion-Skin + RGBA Pixel Diff** highlighting.
- **Code & Data-to-Diagram Generators (`Generate Class Diagram…`, `Generate Module Dependency Diagram…`, `Generate Diagram from SQL / JSON…`)**: Reverse-engineer workspace source files/folders, SQL `CREATE TABLE` DDL schemas, and JSON structures into **Mermaid**, **PlantUML**, or editable **Draw.io** class, dependency, ER, and mindmap diagrams.
- **Workspace Diagram Explorer (`drawGraph.diagramExplorer`)**: Dedicated Explorer sidebar tree with empty-state welcome actions, contextual actions, debounced dual-glob discovery, and expandable Draw.io pages, PlantUML blocks, and Markdown fences.
- **On-Demand Offline Draw.io Engine Pack (`drawGraph.drawio.offlineMode`)**: Keep the default VSIX lightweight while allowing streaming download (with live MB/% progress) or `.war`/`.zip` import of the Draw.io webapp into `globalStorageUri`, served via an ephemeral `127.0.0.1` loopback server for 100% air-gapped editing.
- **Multi-Page Export & Zero-Dependency PDF 1.4 Export**: Export Draw.io, Mermaid, and PlantUML diagrams (including 1/2/4/8-bit PLTE indexed, grayscale, and RGBA PNGs) directly to `.pdf` (also supported in `drawGraph.exportOnSave: "pdf"`), and batch-export multi-page Draw.io `<diagram>` tabs even when unopened.
- **Expanded Diagram Conversions**: Structured `classDiagram`, `erDiagram`, and `mindmap` layout engines in Mermaid-to-Draw.io conversion, plus bidirectional **PlantUML ↔ Mermaid** converters (`DrawGraph: Convert PlantUML to Mermaid` / `Convert Mermaid to PlantUML`).
- **Markdown Diagram Workflows & Offscreen Mermaid Export**: Enriched Markdown fence CodeLens (`Export as SVG`, `Export as PNG`, `Open in Draw.io`, `Extract to .drawio.svg`), local `baseDir` + HTTP `POST` fallback for large Markdown PlantUML fences, and serialized background Mermaid worker rendering.
- **Presentation & Spotlight Mode + Compact Single-Row Toolbar**: Compact `Export ▾` popover menu for narrow split panes, plus distraction-free presentation view (`p` / `Present`) with multi-diagram spotlight highlighting and **Laser Pointer**.
- **Deep Language Intelligence & Instant Static Linter**: Added `DocumentLinkProvider`, `HoverProvider` (C4 macro docs & inline diagram thumbnails), `RenameProvider` (`F2` block-scoped rename), `DocumentColorProvider`, `CodeActionProvider` (`Quick Fix`), PlantUML Stdlib completions, C4 `SignatureHelpProvider`, and zero-subprocess static syntax diagnostics when the preview panel is closed.
- **Architecture, Performance & Security Hardening**: FIFO local PlantUML pipe queue eliminating multi-block Markdown self-cancellation, prefix/suffix minimal range `WorkspaceEdit` on Draw.io saves, `flushPendingEdits()` synchronization, shared protocol discriminated unions, unified host-injected Settings Drawer i18n dictionary, untrusted-workspace CSP/code-link boundary guards, and zero-`innerHTML` Settings Drawer DOM rendering.
